# Learn GitHub

A tiny practice project for learning the everyday GitHub workflow: init, branch, commit, push, and pull request.

## Run it

This project uses [mise](https://mise.jdx.dev) to manage the Python and Poetry versions, and [Poetry](https://python-poetry.org) to manage dependencies.

```bash
mise install       # installs the pinned Python + Poetry versions
poetry install      # installs project dependencies
poetry run python app.py
```
